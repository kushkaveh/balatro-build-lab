# Build Lab

A [Balatro](https://www.playbalatro.com/) mod: a native-styled **custom run builder** (pick deck, stake,
up to five starting Jokers with editions, money/hands/discards, seed, presets) plus the **Impossible**
rarity — five deliberately broken-but-coherent Jokers obtainable only through the Build Lab.

Status: early development (v0.1.0, boots and shows in the mod list). See `docs/` for the plan and
progress.

## Install (players)

1. Install [Lovely](https://github.com/ethangreen-dev/lovely-injector) (copy `version.dll` next to
   `Balatro.exe`).
2. Install [Steamodded](https://github.com/Steamodded/smods) **26.829.0 or newer** into
   `%AppData%\Balatro\Mods\Steamodded` (download: https://download.smods.dev).
3. Drop this folder into `%AppData%\Balatro\Mods\BuildLab`.
4. Launch the game. **Build Lab** appears in the Mods menu.
